# Scripts

这个目录仅保留可公开复现的辅助工具，不是评审台运行入口。日常运行请使用
`award-web`、`award-audit` 和 `award-db`。

| 目录 | 内容 | 适用场景 |
| --- | --- | --- |
| `acceptance/` | M5 单案件和扫描 PDF Graph 验收 | 复现端到端受控验收 |
| `fixtures/` | PDF、视觉和脏数据样本生成器 | 生成可重复的测试材料 |
| `evals/` | M5 离线评测 | 检查脱敏固定测试集表现 |
| `probes/` | OCR、安全、SQLite WAL 通用探针 | 验证关键非功能能力 |

真实提交批次、第三方站点诊断、真实 API 连通性和本地 Web 演示脚本仅保留在
`scripts/local/`，该目录由 Git 忽略，不会进入公开仓库。

所有公开脚本都应使用受控测试数据或由命令行参数传入的路径；不得在脚本中写入 API 密钥、
真实提交材料路径或个人目录。
